Key Capabilities

📷 Visual Image Analysis

Upload images of equipment, serial labels, or components to detect brand, model, and visible ports using Gemini Vision & EasyOCR.

📚 ChromaDB Vector RAG

Index PDF manuals, FAQs, and setup guides with PyMuPDF and Sentence Transformers for high-precision semantic search.

🛠️ Step-by-Step Diagnostics

Get grounded answers with step-by-step diagnostic workflows, error code lookup, and exact document page citations.

💡 How It Works
1. Upload Documents

PyMuPDF extracts text; EasyOCR processes scanned text into vector embeddings.

2. ChromaDB Indexing

SentenceTransformers generates 384-dim dense vectors tagged with product metadata.

3. Grounded Gemini AI

Contextualized prompts generate hallucination-free answers with page citations.
